O sistema

Regras que o CI garante

Arquivo .dependency-cruiser.cjs, rodado por pnpm deps:check em todo push. Hoje: __MODULOS__ arquivos e __DEPS__ imports conferidos, nenhuma violação.

erro

Sem ciclos

Nenhum módulo importa, direta ou indiretamente, quem importa ele.

erro

Shared não conhece os apps

packages/shared nunca importa de apps/. Ele serve aos dois lados.

erro

App e API separados

Conversam só pelo contrato HTTP e pelo shared, nunca por import de arquivo.

erro

Todo import resolve

Caminho quebrado ou pacote não instalado falha o CI.

aviso

Produção sem teste

Código de produção não importa arquivo .spec.
