# @minhasaude/shared

Tipos e validações compartilhados entre `apps/api` e `apps/mobile`.

- `src/enums/` — unidades, tipos de refeição, categorias de marcador de exame
- `src/schemas/` — schemas Zod de domínio
- `src/calculators/` — catálogo extensível de calculadoras de saúde (ver `docs/database-schema.md`)

Ainda vazio — populado conforme os módulos da API forem implementados (Fase 2 em diante).
